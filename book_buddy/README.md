# Book Buddy

Book Buddy is a cross-platform mobile app designed to help users track, organize, and discover books they own, have read, or wish to read. Built with Flutter, Book Buddy streamlines book management and makes it easier for readers to keep on top of their personal libraries.

---

## ✨ Features

- **Personal Library**: Add books to your virtual library with title, author, cover image, and more.
- **Reading Status**: Track books as "Read", "Currently Reading", or "Want to Read".
- **Book Details**: View, edit, or remove detailed book information.
- **Cover Images**: Upload or change book cover images for a visually engaging library.
- **User Authentication**: Secure sign-up and login via Firebase Authentication.
- **Cloud Sync**: Store book data and images with Firebase Firestore and Storage, so your library is backed up and accessible across devices.
- **Responsive UI**: Clean, intuitive design that adapts to both light and dark modes.
- **Future Roadmap**: Planned features include recommendations, social sharing, and reading statistics. (TO DO!!!!!)

## 🚀 Getting Started

> **Note:** A demo video is available here: [Insert Link Once Available]

### Prerequisites

- Flutter SDK (e.g. v3.0+)
- Dart (e.g. v2.17+)
- A Firebase project (see setup instructions)

### Setup

1. **Clone the repository**
    ```bash
    git clone https://github.com/HuttonN/Book-Buddy.git
    cd Book-Buddy
    ```

2. **Install dependencies**
    ```bash
    flutter pub get
    ```

3. **Firebase Configuration**
    - Follow the [official guide](https://firebase.flutter.dev/docs/overview) to create a Firebase project.
    - Add your `google-services.json` (Android) and/or `GoogleService-Info.plist` (iOS) to the project.

4. **Run the app**
    ```bash
    flutter run
    ```
